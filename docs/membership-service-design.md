# 会员服务设计

会员服务页面采用按生成次数收费的商业模式，适合把本地原型、真实 LLM 调用和后续团队协作区分开。

## 方案概览

| 方案 | 价格 | 生成额度 | 适用场景 | 主要能力 |
| --- | --- | --- | --- | --- |
| 免费版 | ¥0 | 真实 LLM 赠送 10 次，本地 mock 不限次 | 产品试用、短篇验证 | 最多 3 章小说试改，YAML 校验、复制和下载 |
| Pro 版 | ¥79 起 | 200 次 | 连续章节改编、真实模型验证 | 支持 OpenAI、DeepSeek、通义等模型，更长章节处理与优先队列，单场景重生成和高级导出 |
| 次数包 | ¥29 起 | 50 / 200 / 1000 次 | 按需补充生成额度 | 适合短篇试改、连续章节、多版本改写和团队批量剧本生产 |

## 次数包

| 套餐 | 价格 | 次数 | 适用场景 |
| --- | --- | --- | --- |
| 轻量包 | ¥29 | 50 次 | 短篇试改和小规模验证 |
| 创作包 | ¥99 | 200 次 | 连续章节和多版本改写 |
| 工作室包 | ¥399 | 1000 次 | 团队项目和批量剧本生产 |

## 额度规则

- 本地 mock 流水线不限次，适合离线演示和开发调试。
- 远程 LLM 生成会消耗真实生成额度。
- 每个本地账号默认拥有 `10` 次真实 LLM 生成额度。
- 管理员可以在用户管理模块查看账号剩余次数、已使用次数和近期使用记录。
- 旧本地账号如果没有额度数据，会自动补齐默认额度结构。

默认额度结构：

```text
totalRuns: 10
usedRuns: 0
usageRecords: []
```

## 与服务商配置的关系

LLM provider 配置已归入会员 / 服务区域统一管理。

当前支持：

- 模型或 API Key 为空时使用本地 mock provider。
- Base URL、模型和 API Key 都配置完成时，使用 OpenAI-compatible 远程调用。
- 工作流入口和用户管理表中展示剩余生成次数。

API Key 仍然只保存在浏览器 `localStorage`，不会写入源码文件，也不会提交到 GitHub。
